# NavoPath 更新日志

## 2026-06-18 · Workspace flow

### 新功能
- Planning 树支持项目、任务和子任务拖动排序，以及任务跨项目移动。
- 月视图支持连续滚动浏览日期。
- 今日候选可以将任务移回 Planning。
- 新增远程 HTTP MCP 和个人访问令牌管理。

- 输入文字时可直接打开添加任务栏。
- 新手指南覆盖完整工作流并可随时重新开始。
- AI 使用用户本地时区判断今天，避免跨时区日期偏移。
- 修复拖动时间轴任务时选中文字的问题。

# NavoPath Changelog

## 2026-06-18 · Workspace flow

### Added
- Drag and reorder projects, tasks, and subtasks in Planning, including cross-project moves and safe level conversion.
- Browse dates through a continuously scrolling Month view.
- Move a task from Today's Candidates back to Planning.
- Connect through the remote HTTP MCP server with revocable personal access tokens.

### Improved
- Type anywhere in the workspace to open Add Task, including Chinese IME composition.
- Follow a six-step, restartable onboarding guide across the complete workflow.
- Resolve relative AI dates from the user's local date and timezone.
- Keep timeline text unselected while dragging and resize scheduled blocks when duration changes.

## 2026-06-10 · Planning polish

### Improved
- Refined Planning interactions and result presentation.
- Refined the timeline quick-add flow.

## 2026-06-08 · Calendar views

### Added
- Added 3-Day, Week, Month, and stacked all-day task views.

### Fixed
- Improved dark-theme compatibility.

## 2026-06-03 · Web launch

### Added
- Launched the NavoPath web app.
