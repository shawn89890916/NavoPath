# NavoPath Project Instructions

For every visual or interaction design task in this repository:

1. Read `NavoPathStyle.md` before inspecting or editing UI styles.
2. Treat `NavoPathStyle.md` as the design-system source of truth.
3. Keep shared application controls bound to the current page theme variables.
   Execute purple and Planning lime are page defaults, not hard-coded global
   control colors.
4. Preserve the existing product workflow and behavior unless the task
   explicitly requests functional changes.
